# SmartCare Hospital Management System

### Connected hospital workflows in a Java application

A **group coursework project** for the CCS1303 Object-Oriented Programming module, connecting a Spring Boot application to a hospital database created for the Database Systems module.

[My portfolio](https://nisith.dev) · [LinkedIn](https://www.linkedin.com/in/nisith-herath-b77014357/)

## Project overview

SmartCare models relationships between hospital records and operational workflows. The project brings together database design, object-oriented development, service logic, APIs, and a browser-based frontend.

## Functional areas

| Module | Purpose |
| --- | --- |
| Patients | Create, view, update, search, and manage patient records |
| Doctors and departments | Organise staff and department relationships |
| Appointments | Coordinate appointment records and business logic |
| Admissions and rooms | Track admissions and room allocation |
| Treatments | Manage treatment and prescription records |
| Laboratory | Manage tests and results |
| Billing | Calculate charges and track payment records |

## Technology

**Java 21 · Spring Boot · Spring Data JPA · MySQL · Maven · HTML / CSS / JavaScript · Postman**

## Architecture

The application is organised into controllers, DTOs, entities, services, repositories, and exception handling. This structure separates HTTP handling, business rules, and database access.

## Academic context

This is collaborative coursework, not a claim of sole authorship. It demonstrates the application of object-oriented programming and relational database concepts to a multi-module system.

## Scope

This portfolio overview is an educational project presentation. It includes no patient data and is not presented as a clinically validated production system.
